## 🔧 Integration Steps

### 1. Landing Page Setup
```
1. Customize HTML file with your copy
2. Update form field names if needed
3. Point form to Encharge webhook
4. Deploy to your hosting (Netlify, Vercel, Kinsta, etc.)
5. Get URL (e.g., https://yoursite.com/content-machine)
```

### 2. Encharge Integration
```
1. Create a new subscriber list for this campaign
2. Create form endpoint that captures emails
3. Auto-subscribe new sign-ups to the list
4. Apply starting tag (e.g., "lead-magnet-subscriber")
5. Set up automation sequence (see email template)
```

### 3. Video Generation
```
1. Use video script from templates
2. Generate with:
   - Remotion (recommended, matches Crosswalk style)
   - HeyGen (fast AI video)
   - Record yourself + edit in CapCut/DaVinci Resolve
3. Upload to video hosting (YouTube unlisted, Vimeo, Bunny)
4. Get embed codes/URLs
5. Insert into email templates
```

### 4. Email Automation
```
1. Create emails in Encharge using templates
2. Insert video embed codes into email bodies
3. Set up triggers:
   - Email 1: Immediate on signup
   - Email 2: 24 hours later at 10 AM
   - Email 3: 24 hours later at 10 AM
   - Email 4: 72 hours later at 10 AM
   - Email 5: 48 hours later at 6 PM
4. Create automation rules for tags
5. Test full sequence
```

## 🎯 The Framework Behind All This

All templates follow the **Hormozi Formula:**

1. **Problem Identification** (Email 1, Video 1)
   - Hook the pain
   - Show you understand
   - Create desire for solution

2. **Framework Teaching** (Email 2, Video 2)
   - Clear, simple system
   - Step-by-step breakdown
   - Real examples

3. **Proof + Opportunity** (Email 3, Video 3)
   - Show results
   - Create curiosity gap
   - Position your offer

4. **Urgency + Close** (Emails 4-5)
   - Bonus incentive
   - Time limit
   - Scarcity

5. **Win-Back** (Emails 6-8, if needed)
   - For people who didn't convert
   - More value + social proof
   - Second chance to buy
