# เว็บไซต์ พลพัฒน์มอเตอร์ (Yamaha สุราษฎร์ธานี)

เว็บไซต์หน้าเดียว พร้อมใช้งาน — ใช้ข้อมูลจริงของร้าน + โลโก้จริง (ดึงมาจาก Facebook)

## 📁 ไฟล์ในโฟลเดอร์นี้
```
polpat-website/
├── index.html      ← หน้าเว็บ (เนื้อหาทั้งหมด)
├── styles.css      ← หน้าตา/ดีไซน์
├── images/
│   ├── logo.jpg       ← โลโก้จริง (จาก Facebook ✓)
│   ├── banner.jpg     ← ป้ายหน้าร้าน + รถรุ่นต่าง ๆ (จาก Facebook ✓)
│   ├── showroom.jpg   ← รูปในโชว์รูม (จาก Facebook ✓)
│   ├── gallery1–3.jpg ← รูปบรรยากาศร้าน (จาก Facebook ✓)
└── README.md          ← ไฟล์นี้
```

(`banner.jpg`, `showroom.jpg`, `gallery1.jpg`–`gallery3.jpg`) — หรือส่งรูปมาให้ช่วยใส่ก็ได้

## 🌐 วิธีเอาขึ้นเว็บให้คนทั่วไปเข้าได้ (ฟรี)
**ตัวเลือกที่ง่ายที่สุด — Netlify Drop:**
1. เข้า https://app.netlify.com/drop
2. ลากโฟลเดอร์ `polpat-website` ทั้งโฟลเดอร์ไปวาง
3. ได้ลิงก์เว็บทันที (เช่น `polpat-yamaha.netlify.app`)
4. อยากได้ชื่อ `.com` ของตัวเองค่อยซื้อโดเมนเชื่อมทีหลังได้

**ตัวเลือกอื่น:** Vercel, GitHub Pages, Cloudflare Pages (ฟรีเหมือนกัน)
